# iOS・Android ストア掲載情報（下書き）

## 変更可能な設定

- 表示名: `APP_DISPLAY_NAME`（現在は TASUKI）
- Expo slug: `APP_SLUG`
- iOS Bundle ID: `IOS_BUNDLE_ID`
- Android Application ID: `ANDROID_PACKAGE`

表示名と説明文は公開後も変更できます。Bundle ID / Application ID は初回公開前に確定し、公開後は変更しません。

## サブタイトル / 短い説明

信頼できる仲間と、案件とオファーでつながる会員専用アプリ

## 説明文

「こんな人を探しています」を仲間に共有し、信頼できるオファーを届け合う、経営者・事業主の会員向けアプリです。

- 仕事・協業先・相談相手などの案件を投稿
- エリア、業種などから案件を確認
- オファーを送るごとに実績とランクを記録
- 案件に写真を1枚添えて、内容をひと目で伝える
- 関連業種の案件だけをプッシュ通知
- 顔写真、会社名、肩書きを表示して相手を確認

営業を一方的にかけるのではなく、まず誰かの課題に対して「この人にオファーできます」とGiveすることから、次の商売と信頼を育てます。

本アプリは、運営が承認した会員だけが利用できる会員専用アプリです。

## 課金設計

- アプリ内に価格、申込ボタン、決済リンク、外部決済への誘導文を置かない。
- 会員契約はアプリ外の独立した営業・Web・対面手続きで成立させる。
- アプリはログイン後の会員機能と契約状態の表示だけを提供する。
- Apple / Google の外部決済プログラムには参加しない。
