# iOS・Android ストア掲載情報（下書き）

## 変更可能な設定

- 表示名: `APP_DISPLAY_NAME`（現在は TASUKI）
- Expo slug: `APP_SLUG`
- iOS Bundle ID: `IOS_BUNDLE_ID`
- Android Application ID: `ANDROID_PACKAGE`

表示名と説明文は公開後も変更できます。Bundle ID / Application ID は初回公開前に確定し、公開後は変更しません。

## サブタイトル / 短い説明

守成クラブの仲間と、信頼できる紹介でつながる会員専用アプリ

## 説明文

「こんな人を探しています」を仲間に共有し、信頼できる紹介を届け合う、守成クラブ会員向けのアプリです。

- 案件・協業先・相談相手などの探しごとを投稿
- 所属会場、エリア、業種などから探しごとを確認
- 紹介を届けるごとに実績とランクを記録
- カメラで名刺を撮影し、本人専用の名刺リストへ保存
- 関連業種の探しごとだけをプッシュ通知
- 顔写真、会場、肩書き、色を表示して相手を確認

営業を一方的にかけるのではなく、まず誰かの課題に対して「この人を紹介できます」とGiveすることから、次の商売と信頼を育てます。

本アプリは、登録済みの守成クラブ会員が利用できる会員専用アプリです。
