# ストアスクリーンショット制作計画

## 出力仕様

- App Store: iPhone 6.9インチ用、縦 `1320 × 2868 px` を基本セットとして1〜10枚
- Google Play: 実機画面を主体にした縦長PNGを同じ構成で用意
- 透過なし、実装済み画面だけを掲載
- サービス名変更が確定してから最終書き出し

## 5枚構成

1. **案件から、信頼できる紹介へ**
   - ホームのバナー、閲覧履歴、ジャンル検索
2. **案件・協業先・相談相手を仲間に共有**
   - 困りごとの一覧と絞り込み
3. **「この人を知っている」をその場で届ける**
   - 紹介フォームと、届いた紹介画面
4. **業種とエリアから、必要な案件だけを見る**
   - 業種グリッドと、絞り込んだ一覧
5. **Giveの実績がランクカードに育つ**
   - 顔写真、会場、色、紹介数、招待した人数を表示したランクカード

## 撮影条件

- 審査用デモアカウントには、顔写真、所属会場、会社、業種、投稿、紹介を準備
- 氏名・会社・電話・メールは架空データだけを使用
- ステータスバー時刻、通知バッジ、電池残量を全画像で統一
- ボタンや文章がセーフエリア、下部タブ、見出しと重ならないことを確認
- 文字サイズを大きくした端末でも崩れないことを実機確認
