# 運営用の管理画面（admin.tasuki.club）

会員向けの画面とは別に、運営が中を見て直すための画面。
**データベースを開かなくても、会員・投稿・広告・ご意見をここから触れる。**

## 誰が入れるか

`ADMIN_EMAILS` に書いたメールアドレスのGoogleアカウントだけ。

**この設定が空のときは、誰も入れない。** 設定を忘れたときに素通りするほうが、
機能が使えないより危ないため。管理用のパスワードは作っていない。
増やせばそれだけ漏れる口が増える。会員と同じGoogleログインを使う。

入れない人には**404の画面**を出す。「権限がありません」と返すと、
そこに管理画面があること自体を教えてしまうため。

---

## 用意する手順（3つ・ターミナル不要）

### 1. 入れる人を決める

Cloudflare ダッシュボード → **Workers & Pages** → `tasuki` →
**Settings** → **Variables and Secrets** → **Add**

| 名前 | 値 |
| --- | --- |
| `ADMIN_EMAILS` | `shaw_futamata@every-counts.com` |

複数の人を入れるならカンマで区切る（`a@example.com,b@example.com`）。
**秘密ではない**ので Secret ではなく普通の変数でよい。

### 2. admin.tasuki.club を生やす

Cloudflare ダッシュボード → **Workers & Pages** → `tasuki` →
**Settings** → **Domains & Routes** → **Add** → **Custom domain** →
`admin.tasuki.club`

同じWorkerが受ける。新しくアプリを作る必要はない。
`admin.` で始まる名前で来た人は、掲示板ではなく管理画面へ送られる。

### 3. Googleログインに、この名前を教える

Google Cloud Console → **APIとサービス** → **認証情報** →
使っているOAuthクライアント → **承認済みのリダイレクトURI** に足す。

```
https://admin.tasuki.club/api/auth/google/callback
```

**これを忘れると、admin.tasuki.club でログインしようとしたときに
Googleが「リダイレクトURIが一致しません」と出して止まる。**

## できること

### 会員

- 一覧（新しい登録順）と検索（名前・会社・メール・会場）
- 会社名・会場・プラン・紹介数・投稿数・登録日
- **利用を止める／戻す**

止めると `membership_status` が `canceled` になり、Webもアプリも入れなくなる。
そのとき、開いたままのスマホアプリのセッションも切る。
戻すと `active` に戻り、そのまま使えるようになる。

自分の行にはボタンを出さない。自分を止めると管理画面から締め出されるため
（画面だけでなく、サーバー側でも断る）。

### 投稿

- 全会員の探しごとを新しい順に。期限切れも募集終了も出る
- 検索（見出し・本文・投稿者の名前とメール）
- **削除**（確認をはさむ）

削除すると、その投稿に届いた**紹介とやり取りも一緒に消える**。
写真と動画（R2）も消す。**元に戻せない。**

> 残っているサンプルの2件も、ここから消せる。
> `docs/sample-cleanup-ja.md` のSQLを流さなくてよくなった。

### 広告

- 申し込みのあった枠を、掲載の新しい順に
- 出稿者・掲載枠・期間・表示数・クリック数・リンク先
- **掲載を止める／戻す**

枠と数字は消さない。お金をいただいているので、記録は残したまま表示だけ止める。

### ご意見

- 会員から届いた「こうしてほしい」を、未読を先に
- **読んだ印を付ける／未読に戻す**

消さないので、あとから読み返せる。

## 作りの約束

- **入れるかどうかは、すべてのAPIの先頭で `getAdmin()` が見る。**
  画面を出し分けるだけでは、URLを直接叩かれたときに守れない。
- 管理画面の操作は `db/admin.ts` にまとめてある。会員向けの
  `db/data.ts` とは分けてあるので、どちらの経路かが読んで分かる。
- **投稿を消す順番は、会員本人の削除と同じ**（やり取り → 紹介 → 投稿）。
  外部キーが効いているので、順番を間違えると止まる。
