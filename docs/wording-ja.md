# 言葉づかいの決まり

同じ言葉を別の意味で使うと、画面でも打ち合わせでも話が噛み合わなくなる。
**特に「紹介」は2つの意味で使われていたので、はっきり分けた。**

## オファー（人を差し出す）

会員が、他の会員の探しごとに対して「この人はどうですか」と人・会社を出す行為。
**このサービスの中心。** ランクはこの数で上がる。

- 画面の言葉 … オファー／オファーする／オファーを送る／届いたオファー／出したオファー
- 数える列 … `members.intro_count`
- 表 … `introductions`、やり取りは `introduction_messages`

**コードの名前（`introductions` / `introCount` / `ReceivedIntroduction` など）は
そのまま。** 表と列の名前を変えると、既に入っているデータとの付け合わせが要る。
見える言葉と中の名前がずれるのは気持ち悪いが、**動いている本番を触る危険のほうが
大きい**ので、変えていない。読むときは「introduction＝オファー」と思ってよい。

## 紹介（会員を招待する）

守成クラブの仲間を `join/<招待コード>` のリンクで会員として招く行為。
1人につき1ヶ月ぶんの利用料が無料になる特典が付く。

- 画面の言葉 … 招待／仲間を招待する／紹介1人につき…（特典の説明だけ「紹介」を使う）
- 表 … `referral_credits`

## そのままの「紹介」

- 業種名の **「人材紹介・派遣」**（`app/industry-options.ts`）
- Stripeの明細に出る **「紹介 N人分の無料月」**（上の「会員を招待する」ほう）

## 直すときの目印

画面に出る文言を足すときは、**人を差し出す話なら「オファー」**、
**会員を招く話なら「招待」**。迷ったら、ランクが上がるほうがオファー。
